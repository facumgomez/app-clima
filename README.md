# App Clima

Este repositorio contiene una aplicación web de clima desarrollada con HTML, CSS y JavaScript.
El proyecto forma parte de mi portfolio personal como desarrollador frontend.

---

## 📌 Descripción

App Clima es una aplicación web que permite consultar el clima actual de distintas ciudades
mediante una interfaz simple y clara. El objetivo del proyecto es practicar JavaScript,
manipulación del DOM y consumo de datos externos.

---

## 🛠️ Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git y GitHub

---

## 🧩 Funcionalidades

- Consulta del clima por ciudad
- Búsqueda de ubicaciones
- Visualización de temperatura y condiciones climáticas
- Diseño responsive
